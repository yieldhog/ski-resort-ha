# Bundled data — sources & licenses

This directory contains derived data generated by
`scripts/build_ski_area_index.py`.

## `ski_area_index.json.gz`
A distilled index of downhill ski areas (id, name, country/region, coordinates,
lift/run terrain statistics, website, Wikidata id) derived from **OpenSkiMap**'s
`ski_areas.geojson`.

OpenSkiMap data is produced from **OpenStreetMap** and **Skimap.org** and is
licensed under the **Open Data Commons Open Database License (ODbL) v1.0**.
© OpenStreetMap contributors; © Skimap.org. https://openskimap.org

## `liftie_crosswalk.json.gz`
A mapping from **Liftie** resort slugs to OpenSkiMap ids, built from Liftie's
per-resort coordinates. Liftie is licensed under the **BSD-3-Clause** license.
© Damian Krzeminski and contributors. https://github.com/pirxpilot/liftie

attribution and share-alike (ODbL) requirements.
